# Changelog

All notable changes to Red Team AI will be documented in this file.

## [1.0.0] - 2024-01-30

### Added
- Initial release of Red Team AI platform
- Multi-agent architecture with Target, Interrogator, and Judging agents
- Six attack strategies: role drift, ethical probing, contradiction, confusion, authority challenge, emotional manipulation
- Comprehensive evaluation metrics: role fidelity, drift index, ethical deviation, consistency
- FastAPI backend with REST API
- React frontend with interactive dashboard
- SQLite database for experiment persistence
- Support for multiple LLM providers (Groq, OpenAI, Anthropic)
- CLI tool for programmatic access
- Docker configuration
- Example scripts and tests
- Comprehensive documentation

### Features
- Create and manage experiments
- Real-time experiment execution
- Turn-by-turn conversation analysis
- Metric visualization with charts
- Export functionality (JSON)
- Extensible architecture for custom agents and metrics
